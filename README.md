# UITKFontFix

Development repository for **UITK Font Fix**
(`jp.colloid.uitk-font-fix`) -- font utilities for Unity UI Toolkit
editor UIs: reliable monospace and Latin+CJK font resolution,
inline/inherited application helpers, display-text sanitization, a
source-level glyph audit and a diagnostics window. Built on TextCore
behavior verified empirically on Unity 2022.3.

## Package

[`jp.colloid.uitk-font-fix/`](jp.colloid.uitk-font-fix/) -- see its
[README](jp.colloid.uitk-font-fix/README.md) for install instructions,
quick start, recipes and the full API reference.

## Install

Unity Package Manager > `+` > *Add package from git URL...*:

```
https://github.com/c-colloid/UITKFontFix.git?path=jp.colloid.uitk-font-fix
```
